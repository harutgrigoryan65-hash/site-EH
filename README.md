# EH Keys

Одностраничный сайт-визитка для продажи цифровых ключей Windows и пакетов Microsoft Office.

## Настройка Telegram

Откройте `script.js` и замените:

```js
const TELEGRAM_BOT_URL = "https://t.me/your_bot";
```

на ссылку вашего Telegram-бота.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический сервер в этой папке.
